# Human-governed development

Status: accepted.

## Context

The project starts with a local single-user CLI and must preserve a path to later capabilities without claiming they exist.

## Alternatives

Always-on agents or autonomous product decisions.

## Decision

Use seven selective specialist roles, bounded concurrency, independent risk-based review and owner approval; maintain elapsed-time log and roadmap.

## Consequences

More transparent work with coordination overhead and unknown timing.

## Revisit

Revisit if tooling or owner policy changes.
