# Security and privacy

Do not publish credentials, private profiles, recruiter messages, browser state or real vacancy text. Report suspected vulnerabilities privately to the repository owner through an established private channel; no public contact channel has yet been configured. Do not include secrets in reports. See the [threat model](docs/threat-model.md) and [source policies](docs/source-policies.md). Enable available repository secret scanning and dependency checks when hosting is configured; neither is configured by this bootstrap.
